Conceptos clave de Git y GitHub

Esta pagina resume el vocabulario basico que el grupo necesita dominar antes de practicar comandos y colaboracion.

Terminos fundamentales

Repositorio

Carpeta del proyecto que incluye archivos y el historial de cambios.

Commit

Registro con mensaje que guarda un conjunto de cambios en un momento concreto.

Branch

Rama de trabajo que permite desarrollar sin afectar la linea principal.

Merge

Union de cambios entre ramas cuando un trabajo ya esta listo para integrarse.

Push

Envio de commits locales al repositorio remoto alojado en GitHub.

Pull

Descarga de cambios remotos para mantener la copia local actualizada.

Como se relacionan entre si

El flujo habitual es modificar archivos, prepararlos, hacer un commit, trabajar en una rama si hace falta y finalmente sincronizar con GitHub mediante push o pull.

Vista rapida para explicar en clase

Repositorio (repo)

La carpeta de tu proyecto + todo su historial de cambios.

Repo local → git push → Repo en GitHub

Commit

Una foto del estado de tu proyecto en un momento concreto. Cada commit tiene un mensaje que describe que cambiaste y te permite volver atras si aparece un error.

  1. Inicio proyecto
  2. Añado HTML
  3. Anado CSS
  4. Arreglado bug en HTML
  5. Version final

Consejos para explicarlos en clase

  • Usa ejemplos concretos de cambios pequenos para explicar un commit.
  • Relaciona las ramas con versiones paralelas del mismo trabajo.
  • Evita mezclar demasiados conceptos en la primera practica.
