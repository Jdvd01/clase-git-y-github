Git vs GitHub

Antes de usar comandos, hace falta distinguir con precision que hace cada herramienta y por que suelen usarse juntas.

En una frase

Git guarda el historial de cambios; GitHub permite compartirlo y colaborar.

Comparacion directa

Git

  • Es un sistema de control de versiones.
  • Se instala y funciona en tu computadora.
  • Permite registrar cambios, crear ramas y volver a versiones previas.

GitHub

  • Es una plataforma para alojar repositorios Git.
  • Permite colaborar, revisar codigo y publicar proyectos.
  • Agrega herramientas como pull requests, issues y GitHub Pages.

Analogia sencilla para clase

Puedes explicar Git como el historial de versiones de un documento y GitHub como el lugar en internet donde ese documento se comparte, se comenta y se coordina.

Cuando usamos cada uno

  • Usa Git para guardar avances de forma ordenada y local.
  • Usa GitHub para respaldar el proyecto y trabajar con otras personas.
  • Usa ambos cuando quieras un flujo profesional y repetible.

Por que GitHub importa mas alla de subir codigo

Para el bootcamp

En el bootcamp, cada proyecto debe quedar subido a GitHub porque ese es el punto de revision de mentores y profesorado. Si no haces commits y no subes los cambios al repositorio, el proyecto practicamente no existe como entrega revisable.

Para la carrera profesional

GitHub tambien funciona como portfolio tecnico. Muchas personas de reclutamiento revisan el perfil para entender en que has trabajado, que tecnologias tocas y con que constancia construyes proyectos.

Para colaborar en equipo

En entornos reales, varias personas suben codigo al mismo repositorio en GitHub. Git se encarga de versionar los cambios y, si hay solapamientos, ofrece mecanismos para detectar y resolver conflictos de forma controlada.
