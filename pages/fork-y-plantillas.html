Fork y plantillas

Dos formas comunes de empezar un proyecto a partir de otro trabajo ya existente.

Diferencia principal

Fork

Crea una copia de un repositorio en tu propia cuenta de GitHub. Sirve para proponer cambios a un proyecto existente sin tocar el original directamente.

Plantilla

Genera un nuevo repositorio usando una base preconfigurada. Es util para tareas, ejercicios, proyectos iniciales o entregas con una estructura comun.

Cuando conviene usar cada uno

  • Fork cuando el objetivo es contribuir sobre un repositorio ajeno.
  • Plantilla cuando quieres empezar desde una base sin conservar el vinculo de colaboracion.
  • En clase, las plantillas funcionan muy bien para repartir un proyecto inicial a todo el grupo.

Ejemplo de practica docente

Puedes compartir un repositorio base con HTML, CSS y JS. El alumnado crea su propio repositorio desde la plantilla, trabaja localmente con Git y luego publica en GitHub Pages.
