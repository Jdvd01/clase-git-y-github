Ruta de clase

Orden sugerido para explicar el contenido

  1. Entender el problema: por que necesitamos controlar versiones.
  2. Distinguir herramientas: Git gestiona cambios y GitHub facilita colaboracion.
  3. Aprender el vocabulario: commits, ramas, merges, remotos y pull requests.
  4. Practicar el flujo: crear, modificar, guardar, sincronizar y compartir.

Puntos clave

Ideas que conviene reforzar durante la clase

  • Git funciona localmente; GitHub funciona como plataforma remota.
  • Un commit registra un cambio con contexto e intencion.
  • Las ramas permiten experimentar sin romper la version principal.
  • Fork y plantillas sirven para partir de un proyecto ajeno o base.
  • Un flujo ordenado reduce errores y mejora la colaboracion.
