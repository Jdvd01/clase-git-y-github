# Proyecto Git y GitHub para GitHub Pages

Sitio estatico en HTML, CSS y JavaScript pensado como material de apoyo para una clase de programacion sobre Git y GitHub.

## Estructura

- `index.html`: portada con resumen de los temas.
- `pages/`: paginas internas por tema.
- `assets/css/`: un archivo CSS por pagina.
- `assets/js/`: un archivo JS por pagina.

## Publicacion en GitHub Pages

1. Sube el proyecto a un repositorio en GitHub.
2. Ve a `Settings > Pages`.
3. Selecciona la rama principal y la carpeta raiz.
4. Guarda los cambios y espera la URL publica.
